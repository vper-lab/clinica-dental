# Clinica Dental Landing

Landing page demo para clinica dental local, orientada a captacion de citas.

## Requisitos

- Node.js 18+
- npm

## Desarrollo local

```bash
npm install
npm run dev
```

Abre `http://127.0.0.1:5173` en tu navegador.

## Scripts

- `npm run dev`: inicia servidor de desarrollo con Vite.
- `npm run build`: genera build de produccion.
- `npm run preview`: previsualiza la build generada.

## Estructura

- `index.html`: estructura principal de la landing.
- `styles.css`: estilos y responsive design.
- `main.js`: animaciones de entrada y feedback del formulario.
